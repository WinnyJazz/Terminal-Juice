# Terminal Juice

Terminal Juice is a web-based beverage ordering application developed specifically for our partner, the Terminal Juice shop, located in the campus canteen. The application aims to digitize and simplify the juice ordering process, improving queue efficiency and order management for customers in the campus area.

### About the Project
This project was developed as the Final Semester Project (UAS) for the Frontend Programming course at Universitas Tarumanagara. Canteen operations often face long queues and inefficient manual ordering during peak hours. This project addresses that issue by providing a centralized web application for digital beverage ordering.

The system provides several core features, including:
- Digital Menu Browsing
- Order Placement and Management
- Cart System
- Order Tracking
